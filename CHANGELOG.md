# Changelog

## Unreleased

### Added

- A structured 16-case songwriting and fusion benchmark with synthetic original inputs, an independent judging protocol, anchored quality scores, and revision-comparison guidance. No real Suno data is required; behavioral results are pending.

- Five genre-writing family references and a coverage router, with lane-specific phrasing, hook, form, and arrangement decisions.
- Deeper songwriting craft: speaker and angle, narrative consequence, hook design, prosody, rhyme architecture, subtext, and targeted revision.
- A role-based genre-fusion workflow with pulse/meter conflict resolution, multi-influence blends, transition design, and exact-lyric version handling.
- A Writing by Genre website page and updated lyric, fusion, workflow, and reference pages.
- Seventeen songwriting/fusion regression scenarios spanning non-pop forms and mixed genres.

- Practical harmony/melody and rhythm/arrangement references, routed from the skill and docs, with musical intent translated into prompt examples.
- Music-knowledge regression prompts for compound meter, modal color, vocal range, arrangement contrast, and controlled v6 comparisons.

- Suno v6 model guidance: `v6`, `v6-wild`, and `v6-mini` selection criteria, the 8-minute per-generation ceiling, and Max Mode cost and timing, in `references/suno-v6-controls.md`.
- Variety slider coverage: it can rewrite the style prompt before generation; set it to 0 for any A/B comparison, persona, or album that depends on exact Style text.
- `references/v6-production-direction.md`: community field notes on directing the performance and the mix, covering instrument activity verbs, vocal character, verse energy, production clauses, ending buffers, and the labeled directed brief as an alternative to a compact Style line.
- A `Say The Plain Meaning First` rule in `references/songwriting-craft.md`, plus cases `PM1` and `PM2`. Asked what a lyric meant, the skill produced an elaborate symbolic reading and inverted the song's actual arc; the plain reading was correct and was never stated. The rule requires one plain sentence before any analysis, tests each device against it, and leads with the plain reading whenever both fit.
- A `Pre-Output Check` in `SKILL.md`, plus regression cases `PO1`-`PO4`. Two packages generated by the previous skill version were reviewed against their own rules: one put an `exclude:` list and a stray `trap` token inside `Style`, and inverted a bridge parenthetical so the production direction sat where the sung words belong; the other carried a reused `Style` line that still promised a spoken French bridge the new lyric did not contain, and used an en-dash in seven of nine section tags. The rules those outputs broke were already stated in `SKILL.md`, so the fix reads the finished fields against each other rather than adding more drafting prose.
- Download budget guidance in `references/studio-and-iteration.md`. Downloads became a resource capped separately from credits on 2026-09-03 (7 lifetime on Free, 20/month Pro, 60/month Premier, Premier Studio exports uncapped), so the skill now treats deciding rather than generating as the expensive step and raises the cost before recommending a multi-download workflow.
- A pre-v6 compatibility section: listen, share, Remaster, Cover, Extend, and Remix are officially guaranteed on songs made with retired models and all re-render on v6; Replace Section, Crop, stems, and the new plain-language editing are undocumented on old songs and are reported as such.
- v6 reference inputs in `references/suno-v6-controls.md`: Suno songs, playlists, audio uploads, images, video, and voice memos, plus mashups and sample-and-isolate. Suno documents that these exist but not their control names, so the skill describes intent instead of naming fields it cannot verify. `Inspire` / `+Inspo` is recorded as the separate, older playlist feature it is.
- Vocal Gender (Male and Female, the only documented values) and the Magic Wand's location at the top right of the Styles box.
- Ten platform regression cases (`MD1`-`MD10`) in `references/evals.md` covering retired-model requests, Variety-driven take variance, Max Mode timing, split production faults, mid-lyric cutoffs, and free-plan routing.
- Download Skill ZIP buttons on the docs Overview and Quick Start pages, a bundled archive, and a reproducible packaging script with a stale-archive check.

- Web documentation page on prompting for songs: reusable briefs, hook exploration, full songs, focused rewrites, instrumentals, adaptation, and actionable iteration feedback.

- Song matrix reference: section jobs, hook and arrangement contrast, prosody, bar/time budgets, and diagnosis.
- Audio Influence guidance, a take comparison log and stopping rule, and Studio 2.0 MIDI/automation routing with official sources checked 2026-09-05.

### Changed

- Retargeted the skill from Suno v5.5 to Suno v6 across `SKILL.md`, `references/`, `README.md`, `agents/openai.yaml`, and the docs site. Suno retired every pre-v6 model on 2026-09-09, so v5.5 and earlier no longer generate new material; the verification stamp is now 2026-09-13.
- Renamed `references/suno-v55-controls.md` to `references/suno-v6-controls.md` and the optional `Suno v5.5 Notes` output field to `Suno v6 Notes`.
- Renamed Custom Mode to Advanced throughout, matching the shipped v6 Create page. Suno's Custom Mode help article still describes a Custom toggle and is behind the UI; `references/suno-v6-controls.md` records that so the naming is not reverted to match the stale article. `Custom Models` and the Duration `Custom` setting are separate features and keep their names.
- Condensed `SKILL.md`, the reference index, and README; synchronized website guidance and harness metadata.
- Expanded web docs with cover-art and validation pages, a worked song matrix, current heuristic slider ranges, take logs, and linked reference files; checked all 19 routes at desktop and mobile sizes.
- Made section counts, genre fusion roles, compact prompts, and slider recipes explicit starting choices instead of universal requirements.

### Fixed

- Removed mandatory chorus simplification, fixed switch-count limits, and automatic transformation of the user's draft. Qualified Rule of 3 and 80/20 as optional heuristics.
- Distinguished Afrobeats from amapiano palette assumptions, funk from disco, phonk branches, and metalcore from heavy music as a whole.

- Recorded Variety in the Advanced tab, confirmed by the user on 2026-09-24; synchronized control guidance, output templates, and web docs.

- Made the no-em-dash and no-en-dash rule explicit for every generated field and surrounding prose, with a final character scan and punctuation regression cases.

- Removed unverified Variety defaults and deterministic-comparison claims; rechecked the official v6 model, release overview, and FAQ sources on 2026-09-24.

- Rewrote `references/personas.md` around what Suno actually provides, confirmed against the shipped UI. Voices and Style Personas are one surface, not two: Style Personas sits in the Voices menu and opens `Create a Voice` (Beta), taking a recorded or uploaded sample of at least 10 seconds, with older Personas converted into that library and reached through `Select from library`. Suno's Voices article still states a 15 second minimum and the Personas button it replaced disappeared back in the v5.5 release of 2026-03-26, so this guidance was stale twice over. The Personas button became Voices in the v5.5 release of 2026-03-26, with Style Personas nested inside it, meaning this guidance was already stale before v6. The file now separates the Markdown spec (a portable brief that selects nothing) from Voices (a verified clone of a real human voice, usable only by its creator), Style Personas, and Custom Models, and tells the agent to confirm the user's Voices menu rather than trusting the help center.
- Replaced the invented heading `Cover / Remix / Restyle` with Suno's documented structure: Remix is the umbrella over Cover, Extend, Reuse, and Speed. There is no tool called Restyle.
- Propagated the Variety rule to every place that depended on a Style line surviving generation: the take-comparison rule in `references/studio-and-iteration.md`, style matching in `references/remix-and-style-match.md`, and the `Suno Defaults` block of both the persona and album spec templates, which now pin `Model` and `Variety: 0` so a saved identity stays reproducible.
- Corrected this session's own claim that the Variety slider was undocumented. Suno's v6 FAQ documents both the mechanism ("adjusting and updating your style prompts") and the fix ("reduce the Variety slider to 0"), so that guidance is now sourced rather than hedged. The intermediate stop labels and per-model defaults remain a single unverified community report and are labeled as such.
- Recorded the measured-not-specified status of field character limits: Suno publishes none, and community counter readings converge on 5,000 Lyrics and 1,000 Styles and Exclude Styles.
- Replaced three help-center citations retired with their models (the v5.5 overview, the per-model song-length article, and the V4.5 detailed-style article) with live v6 sources; the guidance they supported was kept and re-anchored.
- Stated that sliders and square brackets do not belong in the Style field. Slider values are Advanced controls and brackets are lyrics syntax; both are read as ordinary prompt text in Style.
- Corrected the blanket claim that instrumental tracks cannot use Custom Mode Styles, Exclude, or sliders. Portable instrumental labels remain the default.
- Removed unsupported universal character limits, guaranteed ending claims, hidden-filter diagnoses from bland audio, and automatic voice assumptions.
- Distinguished earlier Duration and cover-tool UI observations from currently verified platform behavior.

- "No artist names" guidance: do not pass `sounds like <artist>` into `Style:`; translate the reference into era, scene, rhythm section, signature sound, and production character. Added to `SKILL.md` anti-generic rules, `references/suno-v55-controls.md` (new subsection plus a troubleshooting line), and `references/style-selection.md` (new "Translating Reference Artists" subsection).

- `references/suno-meta-tags.md`: inline lyric cues beyond section headers: instrumental moments (`[Guitar Solo]`, `[Beat Drop]`), vocal delivery (`[Spoken]`, `[Whispered]`, `[Harmonies]`), multiple vocalists (`[Male Voice]`, `[Female Voice]`, `[Duet]`), ad-libs, sound effects, `[End]`/`[Fade Out]` length control, and failure modes.
- `references/genre-palettes.md`: per-lane menu of BPM bands, signature instruments, production textures, vocal identities, and typical structures across pop, rock, hip hop, electronic, folk/country, soul/gospel, world/regional, score, and niche lanes; framed as a picker, not a set of defaults.

- `references/screen-music.md`: anime openings (TV-size form) and endings, TV theme songs / main titles / idents / stings / bumpers, end-credit / needle-drop songs, trailer cuts (three-beat structure), video-game themes, edit-length guidance (full / TV-size / sting / ident), and which formats are vocal songs vs instrumental cues.
- `references/remix-and-style-match.md`: the style-yes/expression-no copyright rule; lyric remix/flip mode; style-match ("in the style of X") mode with style-fingerprint extraction, safe use of web/search, and original-work generation; lyric-style analysis output; `Style Reference:` / `Remix Notes:` output additions and extra checks.
- `references/personas.md`: reusable artist personas: custom vs style-reference (no real names in prompts), the `personas/<slug>.md` spec-file schema (identity, vocals, cadence, lyrical fingerprint, sonic palette / Style kernel, excluded styles, Suno defaults, basis, song log), creating a persona, using one to write a song, output-contract additions, and the no-overwrite rule.
- `references/albums.md`: cohesive albums/EPs: the `albums/<slug>.md` spec-file schema (concept, shared sonic palette / Style kernel, cohesion rules, recurring elements, sequenced tracklist with roles, sequencing notes, excluded styles, Suno defaults, changelog), optional persona link, creating an album, writing a track for one, output-contract additions, and the no-overwrite rule.
- `references/suno-sounds.md`. Suno Sounds (custom audio samples): One Shot vs Loop, BPM, Key; sound categories (SFX & transitions, ambient/background, foley & action, animal, musical samples / drum kits) with example prompts; prompt-writing guidance (recognizable vocabulary, duration, material/space/motion/size); the `Sound:` / `Type:` / `BPM` / `Key` / `Variations` output shape; and the sample-vs-short-piece-of-music routing rule. Based on Suno help article 10625537.
