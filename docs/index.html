Write songs Suno can actually sing.

suno-songwriter is a portable agent skill that helps plan, write, and revise songs for Suno: hooks, lyrics, arrangement maps, prompt fields, and settings when needed. Start with a complete song or work on one passage.

Download Skill ZIP   Installation instructions

Suno v6harness-agnosticno dependencies

A note on use. I don't use Suno for professional music production. I use Suno to create music for my own personal listening, and I built this skill for that kind of use. Install steps for Claude Desktop, Codex, and Claude Code are on the Quick start page.

What it produces

  • Genre writing and blends: five writing families plus musical roles and conflict resolution for mixed styles.
  • Musical direction: harmony and melody, groove and instrumental roles, and section contrast translated into usable prompts.
  • Song plans: a section matrix connecting story, hook, energy, arrangement, and duration.
  • Vocal songs: Title, Style, Excluded Styles, and section-tagged lyrics ready to paste into Advanced mode.
  • Instrumentals: an Instrumental Prompt plus a cue-style Arrangement map, with mapping guidance for the selected Suno interface.
  • Multilingual lyrics: original writing or singable adaptation in the target language, with script and pronunciation decisions stated.
  • Style prompts: compact style prompts built from genre, mood, BPM, vocal identity, instruments, and production texture.
  • Personas and albums: reusable creative briefs for identity, phrasing, sound, and track sequencing.
  • Sounds and cover art: one-shot sample prompts and cover art or animated cover prompts for finished tracks.

Design principles

Choose the hook, story movement, groove, and arrangement from the brief. Review natural stress and breath space before formatting. Chorus-based songs need a clear recurring hook; refrain songs, rap, and through-composed forms follow their own structure. A new request gets its own musical choices, while an album can deliberately retain a shared sound.

It runs on progressive disclosure. A compact SKILL.md handles routing and the core workflow; focused reference files load only when a request needs them. Any harness that can read a skill file and load references selectively can use it.

What comes back

A full vocal request returns the song package. Paste Style into Styles, exclusions into Exclude when available, and sung words into Lyrics. A chorus edit returns the passage; a matrix request returns the plan. Instrumentals use a sound brief and arrangement map. Optional notes and settings appear only when useful.

How To Prompt For Songs

Start with what the song means, how it should feel, and what you want back. Add detail where you have a preference; leave room for choices where you do not.

Start With One Useful Sentence

Use $suno-songwriter to write a bittersweet indie-rock song
about cleaning out my childhood bedroom before my parents move.
Make the chorus feel like relief, with a little guilt underneath.

This gives the song a scene and an emotional turn. You do not need a BPM, key, rhyme scheme, or list of instruments to begin. If the sound is undecided, ask for two or three directions before drafting.

Where this prompt goes: send these requests to the assistant using the skill. Then copy the returned Style, Lyrics, and other applicable fields into Suno. The full songwriting brief is not the text to paste into the Styles field.

Build A Reusable Brief

Copy this and fill only the lines that matter. Plain descriptions such as "slow enough to leave space between phrases" work when you do not have a musical term in mind.

Use $suno-songwriter to write a song.

Story: Who is singing, to whom, and what is happening?
Emotional turn: Where does the singer start and end?
Sound: Genre or groove, energy, and one defining texture.
Vocal: Delivery and character; language or dialect if relevant.
Details: One or two objects, places, habits, or memories to use.
Hook: A phrase to keep, or ask for hook options.
Avoid in lyrics: Words, topics, or an unwanted ending.
Exclude from sound: Instruments, genres, or vocal textures.
Format: Full song, chorus only, matrix, or another specific output.

selected Voice, or available Suno controls, if relevant.

Turn A Mood Into A Song

"A sad song about missing someone" gives a mood. A concrete situation gives the verses something to develop:

Write a restrained soul song from the perspective of someone
who still sets two cups out after a separation. Start with habit,
end with putting the second cup away. Keep the chorus plain
and repeatable. Dry close vocal, brushed drums, electric piano.
Avoid reunion promises. Return a full vocal song package.

The cups supply an image, the action supplies an ending, and the sound supports the intimacy. Choose details from your own story; this is an example, not a required palette.

Find The Hook Before Writing The Song

Use $suno-songwriter to suggest three title-and-hook directions
for a dance-pop song about enjoying a party after my ex leaves.
One playful, one relieved, one quietly defiant.

Plan The Structure

Use $suno-songwriter to plan a 90-second punk theme
about starting over in a new city. Aim for a fast, shoutable hook.

Use the song matrix when you want to settle pacing and contrast first. Approximate bars help budget the draft; the final recording still needs a timing check.

Request A Full Vocal Package

Use $suno-songwriter to write a wiry post-punk song about
working the closing shift while friends are out celebrating.

Use the receipt printer and the last bus as concrete details.

Revise A Passage You Already Like

Use $suno-songwriter to revise only the chorus below.
Keep the title phrase "Leave the Porch Light On" exactly.
Keep the meaning and first-person viewpoint, shorten crowded
phrases, and leave room to hold the last word of each line.
Give two alternatives. Preserve the verses unchanged.

My chorus:
[paste your chorus here]

Say what is fixed and what may change. "Make it better" can invite a broader rewrite than you wanted. Include the surrounding verse if the chorus needs context.

Write An Instrumental Brief

Use $suno-songwriter to plan a no-voice exploration loop
for a small harbor at dawn. Light hand percussion, plucked strings,
a short flute motif, gentle motion without a big climax.
No choir, chants, or vocal chops. Aim for about one minute.
Return Title, Instrumental Prompt, and Arrangement.
My Advanced screen exposes Styles and Exclude; map the brief
into those fields. Include a note on checking the loop seam.

Name the cue's job and whether it loops or resolves. See Instrumentals & Sounds for the difference between a musical cue and an individual sample.

Adapt To Another Language

Use $suno-songwriter to adapt my chorus into Mexican Spanish.
Keep the speaker's meaning and the hook's emotional payoff;
use natural phrasing rather than a word-for-word translation.
Give the lyric in Spanish and briefly explain major changes.

My chorus:
[paste your chorus here]

Specify literal translation if that is what you want. Include a melody or timing reference when the adaptation must fit an existing performance, and request native script or romanization explicitly when needed.

Keep The Priorities Clear

  • Name the two or three qualities that matter most. Resolve conflicts such as "unhurried delivery" and a long lyric in a short cut.
  • Describe musical roles when blending genres: which supplies the groove, which supplies the instruments or phrasing?
  • Keep lyric restrictions separate from sound exclusions.
  • For a song reference, say which broad traits you like: groove, era, texture, or delivery. Ask for original words and imagery.
  • State a target length as a production goal. Tags, BPM, and sliders guide generation; audition and edit the result when precision matters.

Pre-output check

Each field can look correct alone while contradicting the others, so the skill reads the finished package back before returning it:

  • Style carries positive direction only: no exclude: list, no no ... phrase, no slider value, no square brackets.
  • Every token in Style is deliberate. A stray word is read as a genre request, not a typo.
  • Check section and language promises against Lyrics. Place instrumental, harmony, and vocal-layer changes in the intended sections; conflicting fields can produce unwanted results.
  • Parentheses hold sung words only; production direction belongs in the section tag.
  • No em dashes or en dashes in any output field or explanation. Use sentence punctuation and plain hyphens for tags and ranges.
  • Section tag descriptors use a plain hyphen.
  • The last sung line has a section after it when the cut must not clip it.

Plans, Edits, And Other Outputs

A matrix returns section decisions. A focused edit returns the requested passage. Settings-only requests return relevant controls without invented lyrics. Samples and artwork use separate output blocks; add them to a song only when requested.

Workflow & quality gate

The skill writes a song first and a prompt second. The form exists to serve the record.

Core workflow

  1. Clarify the goal: theme, genre, language, vocal or instrumental, audience, emotional arc. Saved personas and albums load first and act as constraints.
  2. Build the song as a song: title, central promise, hook phrase, section map, then lyrics.
  3. Preserve the user's draft at the requested edit depth. For a new song inspired by third-party lyrics, write fresh expression.
  4. Choose the sound from the request; never default to a recurring palette.
  5. Keep Suno fields clean: positive direction in Style, negative in Excluded Styles, cues in the lyrics body.
  6. Run one silent revision pass before output.
  7. Add optional sections only when they earn their place.

The lyric quality gate

Review these for chorus-based songs; adapt them for refrains, rap, and forms without a chorus:

  • The title or hook phrase appears in or near the chorus.
  • The hook has recognizable wording, cadence, or contour. Lower density is one contrast option, not a requirement.
  • Natural stress, phrase duration, and breath space support the intended delivery.
  • Point of view and tense stay stable unless a shift is deliberate.
  • Concrete detail or deliberate imagery supports the song's intended voice and function.
  • Development serves the form: narrative consequence, changed context, instrumental contrast, or purposeful repetition.

Anti-generic rules

Stock filler words (neon, flames, shadows, echoes, fading, forever) are reviewed for purpose. Keep a familiar word when it serves the hook. Living artists are never named in the Style field: the skill translates a reference into era, scene, and production traits instead.

Song Matrix

Give each section a job, a hook behavior, and a musical change. Show the plan when it helps; keep it internal for a simple song request.

Verse 2Add action or consequenceFamiliar rhythm, new evidenceRetain identity; vary one layer

Try A Complete Time Budget

90-second indie-pop plan · 120 BPM · 4/4
Intro          4 bars    Establish the motif
Verse 1        8 bars    Set the situation
Chorus         8 bars    State the hook
Verse 2        8 bars    Add a consequence
Final chorus  12 bars    Return with a changed meaning
Outro          4 bars    Resolve the motif
Total         44 bars   About 88 seconds, plus a short tail

This is one plan, not a required form. A quieter chorus can contrast with a dense verse. A refrain can recur at the end of each stanza. For a game loop, plan a return to the opening harmony and texture instead of a final cadence.

Timing And Prosody

At a steady tempo, seconds = bars × beats per bar × 60 / BPM. In 4/4 at 120 quarter-note BPM, 8 bars take 16 seconds. In 6/8 at dotted-quarter BPM, count two beats per bar. State the pulse unit; leave room for pickups, rests, sustained notes, and tails.

Lyric lines are not bars. Speak the words over the pulse to check natural stress and breath space. A chorus can lift by becoming quieter or less dense. Instrumentals use motifs and cue changes; loops need an audible check of the return boundary.

For musical contrast, choose harmonic motion, melodic contour, groove, and instrumental roles. The harmony and rhythm references translate those choices into prompt language. Exact notes, meter, and timing remain listening checks.

Lyrics & structure

Find the song's angle, develop its sections, and fit the words to the intended performance.

Start with an angle

A topic gives a song territory; an angle gives the singer something to do. Missing home is a topic. I still give the taxi my old address supplies a behavior and a conflict. Decide who sings, to whom, what they want, and what makes that want difficult.

For a dance mantra, image-led lyric, or instrumental, the center may be groove, sound, or a recurring gesture instead of narrative. Choose the form around that center.

Develop rather than restate

SectionUseful jobRevision question
First verseEstablish a person, action, or distinctive voiceIs there a reason to care before the backstory?
Later verseAdd consequence, evidence, or changed behaviorWhat has happened since the first verse?
RefrainReturn to the central recognizable ideaDoes its rhythm, contour, or wording make it memorable?
ContrastChange perspective, tactics, harmony, or textureDoes it earn the time it takes?
Final returnLet context change the familiar materialCan the same words now mean more?

Design the hook

Choose what carries recognition: a phrase, melodic contour, cadence, riff, response, or sound. Place the verbal hook where it lands clearly, then leave enough space to recognize it. A dense chorus can work through patterned rhythm; a short chorus can still be forgettable.

Hook: Keep the photographs, give me back my coat.
Verse 1: trying to sound practical while standing in the hall.
Verse 2: realizing the coat is an excuse to stay another minute.
Final return: the same request now means choosing to leave.

Prosody and rhyme

Fit natural stress to meaningful musical emphasis. I didn't SAY you should leave and I didn't say YOU should leave make different claims. Equal syllable counts do not guarantee equal phrasing.

Choose rhyme arrivals deliberately: quick couplets, alternating lines, internal chains, slant rhyme, or a repeated response. Rewrite the thought when an end word forces unnatural syntax. Perfect rhyme is useful when it serves the voice; slant rhyme is not automatically better.

Leave room for breaths, pickups, sustained vowels, and instrumental answers. A printed line is not a bar or a guaranteed pause. For rap, work against beats and subdivisions; for another language, follow its own phrasing needs.

Choose the form

Verse/chorus is one choice. A story can use stanzas with a refrain, blues can use an AAB lyric within a musical cycle, jazz can use AABA, a theater song can follow changing tactics, and dance music can develop a repeating groove. Read writing by genre before imposing one template.

Revise the cause

  • Generic: give the speaker a specific action or contradiction.
  • Static: change what a later section contributes.
  • Rushed: remove a clause, change the entrance, or allocate more time.
  • Forced rhyme: rewrite the whole thought rather than swapping one word.
  • Flat hook: inspect its landing, cadence, or contrast before adding a build.

Preserve the user's draft at the requested edit depth. A line edit should not silently replace its title or premise. For a new song inspired by third-party lyrics, write fresh expression from broad traits.

Format after writing

[Verse 1 - intimate]
[Chorus - group response]
[Bridge - stripped back]
[Instrumental Outro]
[End]

These are cues, not guarantees. Keep sung responses in parentheses and production instructions out of them. Scan all output for em dashes and en dashes before returning it.

Style & genres

Lead with the defining groove and sound. Keep the prompt compact, expanding when the musical relationship needs explanation.

The style line formula

[Genre/subgenre], [mood], [tempo/BPM], [vocal style],
[instruments and production], [optional theme]
garage rock, restless and defiant, 132 BPM, raw group vocals,
distorted guitars and live drums, punchy basement production

Anti-lock-in

Before a style line ships, the skill asks whether it was chosen for this request or copied from habit. If copied, at least three dimensions change: genre, BPM, vocal identity, rhythm section, lead instruments, production texture, or structure. The genre writing guides cover phrasing, hooks, and form; the expanded palette table supplies optional sound ingredients. BPM bands are examples, not genre boundaries or values to average for a blend.

Reference artists

"Make it sound like [artist]" never passes the name through: Suno documents artist names as a possible moderation trigger. The skill decodes the reference into era, scene, rhythm section, signature sound, and production character. late-90s East Coast boom bap, dusty chopped soul sample, knocking drums travels; a name does not.

Excluded Styles

Short and specific: unwanted genres, instruments, vocal traits, or production moods. Never excludes what Style asks for, and never used to fix lyric problems.

Genre fusion

Give each influence an audible job, then resolve how the parts work together.

Choose the kind of mix

A continuous blend, a section-by-section switch, several versions of one song, and a combination of uploaded sources are different tasks. Decide which result is wanted before writing the prompt.

Allocate the musical roles

LayerDecision
Pulse and grooveShared beat unit, subdivision, drum/bass interaction
HarmonyChord motion, voicing, drone, or modal behavior
PhrasingVocal entrances, cadence, breaths, and responses
Hook and formWhat returns and how the song develops
Timbre and spaceWhich sounds lead and which support

One genre can supply the groove while another supplies the form or vocal language. Anchor-and-accent is an option, not a requirement that one influence own every structural decision. For three or more styles, give each a distinct contribution.

Resolve the collisions

  • Different tempo conventions: state the actual pulse and half-time relationship; do not average genre BPM ranges.
  • Different meters: rephrase onto a shared meter, design a deliberate cross-rhythm, or separate the sections.
  • Busy riff and dense lyric: trade foreground space or simplify one under the other.
  • Two bass identities: choose one foundation, alternate, or move one figure into another register.
  • Story and dance repetition: give narrative detail its own passages and let the groove hook recur.

Worked blend: folk and drum and bass

Folk supplies the speaker, narrative verses, and a changing emotional context for the refrain. Drum and bass supplies rolling breaks and sub. The voice keeps an 87 BPM feel over a 174 BPM grid, with guitar answers in its rests.

folk storytelling over 174 BPM drum and bass, conversational vocal
at an 87 BPM feel, clear title refrain, fingerpicked guitar answers
between phrases, rolling breaks and deep sub; sparse middle passage,
return to the same refrain with fuller percussion

Those numbers describe a relationship between layers. If the words rush, revise their placement or phrase allocation before adding more genre labels.

Worked blend: three influences

Soul supplies a sustained lead and a short backing answer. Post-punk supplies the repeating bass motif and restrained drums. Ambient texture expands in the instrumental gaps. Keep the bass motif through the chorus while the vocal notes lengthen; the lift can happen without more volume.

Plan a switch

Name the last event of the outgoing section, the handoff, and the first event of the new one. A rest, fill, held tone, pickup, or abrupt cut can carry the transition. Preserve a deliberate constant such as the hook or singer. There is no fixed switch-count limit; each change needs a clear musical purpose.

Put the arc in Style and locate it with section cues. If the model smooths away a required change, use an available section edit, Extend, or Studio arrangement. Cues alone cannot enforce the transition.

Make several versions

Name what stays fixed: exact words, melody, hook, story, or only theme. If exact lyrics are required, change placement and arrangement instead of silently rewriting them. When adaptation is allowed, change cadence deliberately and explain meaningful edits. Add controls only when useful.

Use genre writing guides to choose each influence's contribution. The full fusion reference includes conflict diagnosis and additional worked blends.

Instrumental & Sounds

Prepare the sound brief and cue map, then use the fields available in the selected interface.

Instrumental tracks

Lofi, OST cues, game loops, ambient, trailer beds, and background music return an Instrumental Prompt: plus an Arrangement: cue map. For Advanced settings, map the sound brief to Styles and add available Exclude or sliders when useful. Loopable tracks avoid hard endings and mark [Loop Point]; cues describe motif, dynamics, and the emotional turn.

instrumental lofi chillhop study beat, relaxed 78 BPM, dusty drums,
mellow Rhodes, soft upright bass, vinyl texture, loopable, no lead vocals

A mostly instrumental brief may still request voice as texture: wordless chops, choir aahs, and chant hooks are described in the prompt when wanted, and fully excluded (no vocal chops, no chants) when not. Use a vocal-enabled workflow for sung syllables.

Suno Sounds (samples)

Individual samples (a whoosh, a riser, an 808 kick, an ambience bed) are Suno's Sounds feature, not a song. They return a different block: Sound: prompt, Type: (One Shot or Loop), BPM: and Key: for musical material only, and Variations:. Duration is stated in the prompt when it matters: 5-second sci-fi teleport swoosh.

Controls And Scope

Earlier notes recorded square output, 5- or 10-second clips, and roughly 800-character prompt fields. These are prior UI observations. Check the current interface before relying on those values. This skill prepares prompts; it does not claim to have generated an image or video without using a generation tool.

A full multi-scene music video needs a dedicated editing workflow. Keep the song, still-image prompt, and motion prompt as separate deliverables.

Multilingual

Original writing, singable adaptation, or deliberate code-switching, with the language decisions stated instead of assumed.

What gets clarified

  • Target language and dialect: Spanish (Mexico), Arabic (Levantine), Japanese, Korean.
  • Native script, romanization, or both.
  • Original lyrics vs singable adaptation vs literal translation vs bilingual rewrite.

Structure follows the language

English pop density does not transfer. Romance languages need more syllables per idea; Japanese and Korean pop tolerate compact phrases and English hook accents; Spanish hooks favor open vowels over exact rhyme. "Korean music" spans ballad, K-hip hop, K-R&B, indie, OST, and trot, not just K-pop, and the skill asks or infers which lane.

Pronunciation

AI vocal models anglicize vowels and mis-stress unfamiliar words. The skill plans for it: in-line phonetic respelling for words that reliably break, a separate Pronunciation Notes: block otherwise, and a native-speaker review recommendation whenever release quality matters.

Hitting the cut

Budget the cut with bars, pulse, phrase space, and an ending tail. Use Duration if the current interface exposes it, then audition and Crop or edit to the required time. A prompt or ending tag cannot prove exact length or loopability. See the song matrix for timing examples.

Style match & remix

Describe broad musical traits and write original lyrics, while preserving user-supplied wording when a close edit is requested.

The hard rule

Cadence, rhyme strategy, structure, subject matter, and genre are free to write like. Specific lyrics, hooks, and distinctive phrases are not: never reproduced, closely paraphrased, or continued. Artist names stay out of the Style field, while the prompt describes the musical traits directly.

Style-match workflow

  1. Fingerprint the source: cadence and flow, rhyme density, line shape, diction register, POV and themes, and the sonic lane.
  2. Sharpen with search when available, pulling descriptions of the style, never verbatim lyrics.
  3. Generate original work on a fresh subject so the result is its own song, not a re-skin.
  4. Declare it: a Style Reference: line names what was modeled and states that all lyrics are original.

Remix mode

For lyrics the user owns, close rework is fine: the skill states in one line what is kept (premise, arc, a motif) and what changes (genre, structure, images), then rewrites. Ownership gets confirmed when it is ambiguous, and requests for actual copyrighted lyrics are declined with a style-match offered instead.

Personas & albums

Consistency across many tracks, stored as small spec files in your project, not in the skill.

Personas

A persona is a reusable artist: identity, vocals, cadence, lyrical fingerprint, sonic palette, excluded styles, and Suno defaults, saved at personas/<slug>.md in your working directory. Later requests like "write this as [persona]" load the file and treat it as a constraint. Style-reference personas decode a real act into a fingerprint and keep the name out of every prompt; the persona is a fictional act with your chosen name.

A Markdown persona is a creative brief. It does not select or train anything inside Suno, and it cannot guarantee the same rendered singer.

Voices and Style Personas are one surface. Style Personas sits inside the Voices menu and opens Create a Voice (Beta): record or upload a sample, and Suno uses it to influence how your generated songs sound. Older Personas were converted into that library and are reached through Select from library. The UI asks for at least 10 seconds, sung in the style and language you want, recorded somewhere quiet. Only the creator can generate with a Voice.

Custom Models are a separate feature: a private model trained on at least 6 of your own songs, max 3 per account, now running on v6. A model is not a voice.

The skill keeps these distinct and asks what your screen shows rather than trusting the help center, which has lagged the shipped UI repeatedly, including on this feature's own minimum sample length.

Albums

An album spec at albums/<slug>.md adds a concept, a shared Style kernel, cohesion rules (what stays constant vs what varies track to track), recurring elements, and a sequenced tracklist. Writing "track 4 of [album]" builds the song as the album's kernel plus that track's mood and theme, then updates the tracklist and the persona's song log in the same pass.

Spec files are never overwritten without confirmation. They live in your project so they travel with your work, not with the skill.

Variety: Advanced tab

Open the Advanced tab and adjust Variety there. Its location was confirmed in the user's interface on September 24, 2026. Keep the setting out of Styles and Lyrics.

Suno's v6 FAQ documents that Variety can rewrite your style prompt. Set it to 0 when retaining exact Style text for comparisons or a consistent persona or album. Raise it deliberately for exploration. Intermediate labels and per-model defaults remain unverified; use the control displayed in your account.

Variety 0 preserves prompt control, not identical audio. Hold model, source, other settings, and personalization constant when comparing takes.

Vocal Gender

A dropdown with two documented values, Male and Female. It steers the singer; it does not select a Voice and does not replace describing register, texture, and phrasing in Style.

Max Mode

Max Mode spends more credits per generation for consistency and fidelity: long songs, faithful covers, style transfer, and holding vocals steady across a track. Leave it off while calibrating a brief, because extra credits do not fix a prompt problem. A baseline generation is two songs for 10 credits; Suno says Max Mode costs more without publishing a multiplier.

Downloads are the binding limit

Since September 3, 2026 downloads are capped separately from credits: 7 lifetime on Free, 20 per month on Pro, 60 per month on Premier, with Premier Studio exports uncapped. One song is one download whatever the format, and its stems come inside it. Credits buy far more generations than downloads allow releases, so the skill treats deciding as the expensive step and says to compare inside Suno before spending one.

Lower is not automatically safer: if lowering Weirdness makes a take break down, return to the last working setting and compare with the same prompt and model. Do not keep lowering it as a stability fix.

Duration

All v6 variants generate up to 8 minutes in one pass. Use the range shown in your current interface; a 0:10-6:00 Custom setting is a reported UI observation, not a limit verified in this audit. Write the structure to fit the target, give the last lyric a section to land after it, and check the audio before trimming.

Personalization

  • Voices: with a trained Voice selected, the skill stops over-describing the vocal and trusts the Voice.
  • Custom Models: prompts aim at song intent instead of fighting the model with contradictory genre tags. Existing custom models were carried over and now run on v6.
  • My Taste: the Styles-field Magic Wand seeds personalized ideas; the skill then edits for specificity.

Harmony & melody

Give a hook a recognizable shape and choose how the chords move beneath it. Use musical detail when it changes the song.

Choose the motion

Harmonic rhythm is how often chords change. Holding a chord for two bars can leave room for a story; changing each bar can add motion without increasing tempo or volume. More chords are not automatically better.

GoalMusical choicePrompt language
Grounded verseTonic pedal under moving voicingsSteady home-note bass beneath shifting upper chords
Firm arrivalDominant-to-tonic cadenceChorus resolves firmly onto the home chord
Unresolved refrainDelay the return homeRefrain hangs open before the next verse
Lift without louder drumsFaster chord changes and a higher melodic contourChorus chords turn each bar beneath a higher sustained title phrase

Color with a purpose

Dorian combines a minor third with a natural sixth. For a D-centered vamp, Dm-G can expose the B natural that gives that color. Mixolydian combines a major third with a lowered seventh. Neither mode guarantees a mood; rhythm, melody, register, and instrumentation shape the result.

Use chord names when numeral conventions could confuse the brief. C-G-Am-F and Am-F-C-G share a chord collection, but melody, bass emphasis, and cadences can establish different tonal centers. A loop alone does not prove the key.

Make the hook recognizable

  • Repeat a short rhythmic cell, then vary the ending at a meaningful turn.
  • Give the title phrase a clear contour or a sustained note with room after it.
  • Align important syllables with accents; use pickups to let weaker syllables lead into them.
  • Reduce competing note changes when a phrase feels busy.

Range and tessitura: range is the lowest-to-highest span; tessitura is where most of the part sits. A singer who can reach E4 may still tire if every phrase stays there. Keep repeated hooks in the singer's comfortable register rather than inferring range from gender or voice labels.

Worked prompt

For a folk-rock chorus that lifts without getting louder, keep percussion restrained while the melody rises and chords change more often:

folk rock, steady brushed backbeat, fingerpicked guitar;
close conversational verses, chorus chords turn each bar
beneath a higher sustained title phrase, restrained dynamics

These are musical intentions, not additional Suno controls. Exact notes, chords, and key need listening checks. Use a supported recorded or MIDI reference when precision matters.

Read the harmony and melody reference for modal color, voice leading, and hook revision. Continue with rhythm and arrangement.

Rhythm & arrangement

Describe the pulse, give each instrument a job, and choose what changes when a new section arrives.

Tempo is only one decision

DecisionExampleWhat it changes
Meter6/8, two dotted-quarter beats per barHow beats group
SubdivisionStraight sixteenths or swung eighthsMotion within the beat
BackbeatSnare on beat 3 in 4/4A half-time impression at the same BPM
PocketRelaxed phrasing behind the beatPlacement against the pulse, without slowing down
DensityBusy hats above sustained bassActivity without changing tempo

3/4 normally groups three quarter-note beats; 6/8 groups two dotted-quarter beats, each split into three eighths. At dotted-quarter 72 BPM, eight bars of 6/8 take about 13.3 seconds: 8 x 2 x 60 / 72. State the pulse unit before using a bar budget.

For a half-time electronic groove, 140 BPM, half-time backbeat, active sixteenth-note hats separates tempo from feel. Faster hats do not automatically mean double-time.

Give each part a role

RoleDirection
PulseKick and bass anchor the downbeat; shaker carries subdivisions
HarmonyGuitar or keys leave space around the singer
HookOne lead instrument repeats an identifiable figure
AnswerShort fills occupy the gaps after vocal phrases
TextureA pad or drone adds depth beneath the foreground

If parts compete, separate their register, rhythm, articulation, or entrances before adding mix adjectives. Ask a lead guitar to answer vocal rests rather than solo continuously over every line.

Contrast by section

Choose one or two changes at a boundary and keep an identity anchor: the groove, motif, singer, or recurring instrument. Fuller verses can lead into a bridge of bass and voice. Scope those directions to their sections so a global full-band instruction does not contradict the bridge.

ska punk, 164 BPM, clipped offbeat guitar upstrokes,
walking bass, tight snare backbeat; brass answers vocal rests,
gang responses on the chorus
slow soul in 6/8, dotted-quarter pulse at 64 BPM,
triplet piano figures, restrained bass, brushes;
lead vocal leaves space for short organ answers

Listen for the result

Check pulse, foreground part, breathing room, section contrast, and ending. At edit boundaries, listen for aligned downbeats, compatible chords, sustained notes, and reverb tails. A loop tag cannot prove a clean join.

Read the rhythm and arrangement reference, or use production direction to expand a dense brief.

Production direction

Name what the musicians do and how the sections behave. Expand a compact Style line only when the arrangement needs it.

These prompting techniques are community field notes and musical starting points, not documented v6 guarantees. Compare the result with your own listening priorities.

Describe activity

HornsShort brass shots on offbeats, saxophone answering vocal lines

A directed brief

Use only the labels the song needs. Keep slider values in the Advanced tab, and negative direction in Excluded Styles.

Genre: cumbia sonidera with dub bass weight and surf guitar.
Vocals: conversational tenor, group responses on the hook.
Drums: steady guira and timbale pattern, fills at transitions.
Bass: round electric bass, long sustained roots.
Other: tremolo guitar lead, spring reverb organ stabs.
Arrangement: active percussion beneath each verse.
Production: close-mic lead, clear instrument separation.
Ending: complete the final lyric, short instrumental outro.

Fix a named problem

For a distant vocal, try close-mic presence. For blurred instruments, simplify overlapping parts or ask for separation. Keep the musical brief ahead of a long list of production adjectives. A prompt cannot certify the mix.

If the final lyric gets clipped, give it an instrumental outro to land into. If the outro runs long, audition and trim it. [End] requests closure but cannot enforce a duration.

Keep the exact prompt and settings for a useful take. See Studio and iteration for comparisons and local edits, or read the full production direction reference.

Writing by genre

A genre changes how a song moves, phrases, repeats, and creates expectation. Choose those decisions before the instrument list.

The skill now routes songwriting through five families. They provide broad working coverage with different levels of detail, not an exhaustive taxonomy. Load only the family and sections relevant to the song; combine them through genre fusion for hybrids.

Pop, roots, soul, and groove

Pop, synthpop, art pop, country, folk, Americana, bluegrass, blues, soul, R&B, gospel, worship, funk, and disco.

Choose between a clear topline, a narrative refrain, an instrumental answer, or a groove-led response. A country story needs a speaker's angle; a blues AAB lyric needs response space; a soul vamp can develop through changing lead phrases over a fixed answer.

Read the pop and roots writing guide.

Rap, rock, and heavy music

Boom bap, trap, melodic rap, drill, grime, punk, indie rock, post-punk, shoegaze, grunge, metal, metalcore, and progressive forms.

Map rap accents, rhyme landings, and breaths against the beat. For rock and metal, decide whether the riff supports, answers, or replaces the vocal foreground. Hookless rap and metal without clean choruses are valid forms, not incomplete pop songs.

Read the rap, rock, and heavy writing guide.

Electronic and experimental

House, techno, trance, drum and bass, jungle, UK garage, dubstep, hyperpop, trip-hop, ambient, drone, and chiptune.

Choose the repeating unit, what stays fixed, and which small changes matter. A club arrangement, vocal single, game loop, and ambient listening piece need different forms. Not every track needs a build, drop, or narrative climax.

Read the electronic writing guide.

Regional and diasporic traditions

Reggae, dub, dancehall, soca, calypso, reggaeton, salsa, cumbia, bachata, merengue, bolero, Brazilian and Mexican directions, Afrobeats, Afrobeat, amapiano, highlife, and soukous.

Distinguish the requested branch, language, rhythm, and song function. Afrobeats and Afrobeat are different terms; a corrido's narrative form is not an instrument list; cumbia has regional treatments. Preserve those distinctions when blending styles.

Read the regional and diasporic writing guide.

Jazz, stage, and screen songs

Jazz standards, modal jazz, fusion, musical theater, chanson, cabaret, art song, J-pop/J-rock, Korean pop and ballad, South Asian film/pop, and Arabic pop.

Jazz forms can return to a melodic A section without a modern chorus. A theater song can develop through a character's changing tactics. Language and film-industry labels need a more precise musical brief. Raga and maqam systems need their own melodic context, not a generic scale tag.

Read the jazz, stage, and screen writing guide.

When a lane is missing

Use a specific reference or reliable practitioner, educational, or cultural source. Identify groove, phrase behavior, form, and context before prescribing unfamiliar terms. Describe a contemporary hybrid honestly when that is the goal; a few instrument tags cannot establish traditional authenticity.

The genre writing router maps the full coverage. The palette menu remains a source of sound options after the writing decisions are made.

Validation

Check the written package separately from the generated recording.

Text Review

  • The response matches the requested scope, including matrix-only or passage-only requests.
  • Fields map to the selected interface; Variety belongs in the Advanced tab.
  • No em dashes (U+2014) or en dashes (U+2013) appear anywhere in the response, including lyrics, notes, explanations, and code blocks. Use sentence punctuation and plain hyphens for tags and ranges.
  • Hooks, section movement, natural stress, and vocal constraints match the brief.
  • Time budgets use an explicit pulse unit; tags and settings are not presented as guarantees.

Listening Review

Check hook delivery, pronunciation, groove, identity, transitions, ending, and loop boundaries against actual audio. Text review cannot pass these checks. Record untested behavior as pending.

Songwriting And Fusion Benchmark

A structured 16-case benchmark tests editing scope, narrative development, rap cadence, non-pop forms, genre identity, and mixed-style decisions. It uses self-contained briefs and synthetic original drafts, so it needs no real Suno recordings or before-and-after dataset.

The protocol separates fresh generation sessions from blind judging, scores four quality dimensions, and reports constraint failures separately. It includes comparison procedures for skill revisions. The suite is authored but has not been run; validation of the files is not evidence that the agent passes.
